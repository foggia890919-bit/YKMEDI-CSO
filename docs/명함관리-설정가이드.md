# 명함관리 설정 가이드

박람회 등에서 받은 명함을 **앞/뒤 촬영 → OCR 자동인식 → 메모 → 구글시트 주소록 실시간 연동**까지 한 번에 처리하는 기능입니다.

- 접속: `https://ykmedi.com/명함관리.html` (관리자페이지 상단 **명함관리** 버튼)
- 로그인: 기존 관리자(Supabase) 계정 그대로 사용

## 1. Supabase 테이블 만들기 (최초 1회)

Supabase 대시보드 → **SQL Editor** 에서 아래 SQL을 실행하세요.
(명함관리 페이지 → **설정 탭 → SQL 복사** 버튼으로도 복사할 수 있습니다.)

```sql
-- 계정(user_id)별로 명함이 분리 저장됩니다 — 여러 회원이 각자 자기 명함만 봅니다.
create table if not exists public.business_cards (
  id uuid primary key,
  user_id uuid not null default auth.uid(),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  name text, name_en text, company text, department text, title text,
  mobile text, phone text, fax text, email text,
  website text, address text, country text,
  met_event text, met_date text, memo text,
  front_url text, back_url text, ocr_text text
);
-- (이전 버전으로 이미 테이블을 만든 경우) 아래 두 줄만 실행
-- alter table public.business_cards add column if not exists name_en text;
-- alter table public.business_cards add column if not exists country text;
create index if not exists business_cards_user_idx
  on public.business_cards (user_id, created_at desc);

alter table public.business_cards enable row level security;

create policy "cards own select" on public.business_cards
  for select to authenticated using (user_id = auth.uid());
create policy "cards own insert" on public.business_cards
  for insert to authenticated with check (user_id = auth.uid());
create policy "cards own update" on public.business_cards
  for update to authenticated using (user_id = auth.uid()) with check (user_id = auth.uid());
create policy "cards own delete" on public.business_cards
  for delete to authenticated using (user_id = auth.uid());
```

> 명함이 **계정별(user_id)로 분리**되도록 설계되어 있어, 나중에 회원가입을 열고 유료 멤버십(SaaS)으로 확장할 때 스키마 변경 없이 그대로 쓸 수 있습니다.

명함 사진은 기존 `assets` 스토리지 버킷의 `cards/` 폴더에 저장됩니다(추가 설정 불필요).

> 테이블을 만들기 전이거나 인터넷이 불안정해도 명함은 **기기(브라우저)에 임시 저장**되므로 현장에서 데이터가 유실되지 않습니다. 목록에서 "이 기기" 표시가 붙은 명함이 로컬 저장분입니다.

## 2. AI 정밀 인식 켜기 (99% 정확도 — 필수 추천)

기본 인식(Tesseract)은 무료지만 한글 명함 인식률에 한계가 있습니다.
**AI 정밀 인식**을 켜면 Claude AI가 명함 사진을 직접 읽어 사실상 완벽하게 추출합니다.

### 방법 A — API 키 붙여넣기 (3분, 대표님 혼자 쓸 때 추천)

1. [console.anthropic.com](https://console.anthropic.com) 가입 → 결제수단 등록 → **API Keys**에서 키 발급
2. 명함관리 → **설정 탭 → AI 정밀 인식 → 키 붙여넣기 → 키 저장** — 끝.

키는 이 기기(브라우저)에만 저장되고 서버에는 올라가지 않습니다.
비용은 명함 1장당 약 30~40원(claude-opus-5 기준)이며 발급 계정에서 충전 방식으로 결제됩니다.

### 방법 B — 서버(Edge Function) 배포 (여러 직원·유료회원 서비스용)

키를 각자 입력할 필요 없이 서버가 대신 호출합니다. **CLI 설치 없이 Supabase 웹 대시보드에서 가능합니다:**

1. [Supabase 대시보드](https://supabase.com/dashboard) → 프로젝트 → **Edge Functions → Deploy a new function → Via Editor**
2. 함수 이름을 `card-ai-ocr`로 하고, 저장소의 `supabase/functions/card-ai-ocr/index.ts` 내용을 붙여넣고 **Deploy**
3. **Edge Functions → Secrets**(또는 Project Settings → Edge Functions)에서
   `ANTHROPIC_API_KEY` = 발급받은 키 추가
4. 앱 설정 탭에서 API 키 칸을 비워두면 자동으로 서버 방식이 사용됩니다.

(CLI가 편하면: `supabase functions deploy card-ai-ocr` + `supabase secrets set ANTHROPIC_API_KEY=...`)

### 공통 참고

- 모델 기본값은 `claude-opus-5`(최고 정확도). 서버 방식에서는
  `CLAUDE_MODEL=claude-haiku-4-5` 시크릿으로 저가 모델 전환 가능
  (실측: 명함 34장 테스트에서 haiku급으로도 충분 — 장당 약 5~10원)
- AI 호출이 실패하면(키 없음·잔액 부족 등) 자동으로 기본 인식으로 전환되어 사용이 끊기지 않습니다.
- 회전된 명함 사진도 보정 없이 인식됩니다. 단 **HEIC 사진은 미지원** — 아이폰은 카메라 설정 "높은 호환성(JPEG)" 권장.

## 3. 구글시트 주소록 실시간 연동 (최초 1회)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (예: `YKMEDI 명함주소록`)
2. 시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
3. 명함관리 페이지 → **설정 탭 → 코드 복사** 버튼으로 연동 스크립트를 복사해, Apps Script 편집기에 전체 붙여넣고 저장합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (URL을 아는 사람만 호출 가능하며, 시트 자체가 공개되는 것은 아닙니다)
5. 발급된 웹앱 URL(`https://script.google.com/macros/s/…/exec`)을 명함관리 → 설정 탭에 붙여넣고 **연동 저장**을 누릅니다.
6. **연결 테스트**로 확인 후, 기존 명함이 있다면 **전체 명함 → 시트 동기화**를 한 번 눌러줍니다.

이후에는 명함을 저장/수정/삭제할 때마다 시트의 `명함주소록` 탭에 자동으로 반영됩니다.
시트 열 구성: 등록일 · 이름 · 회사 · 부서 · 직함 · 휴대폰 · 전화 · 팩스 · 이메일 · 홈페이지 · 주소 · 만난 행사/장소 · 만난 날짜 · 메모 · 명함(앞/뒤 이미지 링크). A열(ID)은 동기화용으로 숨김 처리됩니다.

## 4. 사용 방법

1. **명함 등록 탭**: 앞면/뒷면 촬영(또는 앨범 선택) → **글자 자동인식(OCR)** 버튼
   - 회사명·이름·직함·휴대폰·전화·팩스·이메일·홈페이지·주소가 자동으로 채워집니다.
   - **AI 정밀 인식**이 켜져 있으면 Claude AI가 읽고(권장), 꺼져 있거나 실패하면 브라우저 내장 인식(Tesseract)이 자동으로 대신합니다. 기본 인식은 첫 실행 시 엔진 다운로드로 수십 초 걸릴 수 있습니다. 인식 결과는 반드시 확인 후 수정하세요.
2. **만남 기록**: 만난 행사/장소, 날짜, 소통 메모(나눈 대화·후속조치)를 입력하고 저장합니다.
   - 행사명은 저장 후에도 유지되어 같은 박람회에서 연속 등록이 편합니다.
3. **목록 탭**: 이름/회사/메모 검색, 행사별 필터. 명함을 누르면 수정·삭제할 수 있습니다.
4. **설정 탭**: 구글시트 연동 관리, 전체 동기화, **주소록 CSV 다운로드**(엑셀에서 바로 열림).

## 5. 이전 명함관리 도구(단일 HTML)에서 데이터 이관

로컬 단일 HTML 도구(`OneDrive/클로드/클로드코드 프로젝트/명함관리/명함관리.html`)로 등록해 둔 명함(17명)은 다음 순서로 이관합니다:

1. 이전 도구를 열고 **JSON 백업 내보내기**를 눌러 `.json` 파일을 저장합니다.
2. 이 앱의 **설정 탭 → JSON 백업 가져오기**로 그 파일을 선택합니다.
3. 이름(로마자/한글), 전화(tel→전화), 태그(→메모), 썸네일이 자동 변환되고,
   **이메일·휴대폰이 같은 명함은 중복으로 자동 제외**됩니다.
4. 완료 후 안내에 따라 구글시트 전체 동기화를 실행하면 시트에도 반영됩니다.

이관 후 이전 도구는 폐기하거나 열람용으로만 보관하세요. (양쪽에 계속 저장하면 데이터가 갈라집니다)

## 팁

- OCR 인식률을 높이려면: 밝은 곳에서, 명함이 화면에 꽉 차게, 정면에서 촬영하세요.
- 촬영 즉시 정보 입력이 어려운 현장에서는 **사진만 찍고 저장**해두고, 나중에 목록에서 열어 OCR을 돌려도 됩니다.
