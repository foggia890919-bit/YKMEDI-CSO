# tools/settlement-tool.html — 정산내역서 도구 (흡수율 기능 포함 개발본)

`ykpharm-partner/public/settlement-tool.html`(영업포털 `/tools/settlement`에서 iframe으로 로드)의 개발본.
이 파일을 `ykpharm-partner/public/settlement-tool.html`로 교체하면 배포 반영됩니다.

## ⑤ 흡수율 탭 (신규 구현)

- **🏢 거래처관리(병원·약국 일원화)**: 병원과 약국을 하나의 마스터로 등록·관리(구분 배지). 명칭·사업자번호·주소·담당자 입력, 검색/전체·병원·약국 필터.
  - **병원 행**: ▸ 펼쳐보기로 매핑된 약국 목록 확인, 그 자리에서 약국 드롭다운으로 매핑 추가.
  - **약국 행**: 매핑된 병원이 칩으로 표시(구분·거리 포함), 등록된 병원 드롭다운 + 구분(문전/근처/도매) 선택으로 매핑 추가.
  - [👥 거래처 가져오기](영업포털 /api/clients), [🧾 ②병원 가져오기](정산내역 취합분) 일괄 등록. 엑셀 양식/대량등록(매핑병원 열로 매핑까지 일괄).
  - **거리검증(문전 500m)**: 주소 입력 후 [📏 전체 거리계산](카카오 지도 API, ⚙ 지도API에서 JavaScript 키 설정)으로 좌표화. 병원↔약국 500m 초과면 문전 매핑이 차단되고(alert), 기존 문전 매핑도 거리계산 시 자동으로 근처 해제. 거리 미검증 상태의 문전 등록은 확인창 후 허용.
  - 카카오 키: developers.kakao.com → 앱 키 → **JavaScript 키**, [플랫폼>Web]에 배포 도메인 등록 필요. 키는 localStorage(`absorb_kakao_key`)에만 저장.
- **📝 실적입력(처방)**: 등록된 **병원을 드롭다운으로 선택**해 품목별 수량 입력. ② 정산내역 취합 수량 자동 포함(체크로 on/off) + 엑셀 대량등록(미등록 병원 자동 등록).
- **🚚 사입자료**: 문전약국/종합도매 유통자료 엑셀 업로드 — 약국(공급처)·병원·품목·보험코드·수량·월 열 자동인식, 🔧 열매핑으로 수정. 약국명 열이 없는 단일 약국 파일은 공급처명·기준월 지정. 수기 입력은 등록된 **약국 드롭다운 선택**.
- [🔍 약국찾기]로 매핑 추가 시 미등록 약국은 거래처관리에 자동 등록됨(근처 구분).
- **📊 흡수율 현황**: 월별 병원별 품목별 흡수율(사입÷처방) 계산. 기준%(기본 80%) 미달은 대체조제 의심 → 정산 보류 검토 표시. 미달 행의 [🔍 약국찾기]로 같은 품목을 사입한 미매핑 근처 약국을 보고 클릭 한 번으로 추가 매핑해 최대한 맞춤. 상세(당월/합산)·월별 추이 뷰, 미달만 필터, 엑셀 내보내기.
- 저장: 수기 실적/사입/매핑/설정은 localStorage(`absorb_*`), 유통자료 파일은 IndexedDB(`absorb_db`) — 기존 내역서 저장 방식과 동일하게 브라우저에 유지.
