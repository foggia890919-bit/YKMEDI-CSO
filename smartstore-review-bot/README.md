# 스마트스토어 리뷰 자동 답글 봇

네이버 스마트스토어 리뷰를 읽고, **Gemini가 리뷰 내용을 이해해서 사람이 쓴 것 같은 답글**을 생성해 자동으로 등록하는 봇입니다.

## 왜 브라우저 자동화인가?

네이버 커머스API에는 리뷰 조회/답글 API가 **없습니다** ([네이버 공식 답변, 2024.8](https://github.com/commerce-api-naver/commerce-api/discussions/1909) — "가까운 시일 내 제공 계획 없음"). 그래서 유일한 방법은 스마트스토어센터 화면을 브라우저 자동화(Playwright)로 조작하는 것입니다.

```
[스마트스토어센터] --Playwright--> [리뷰 수집] --Gemini API--> [답글 생성] --Playwright--> [답글 등록]
```

## ⚠️ 사용 전 반드시 알아야 할 것

1. **네이버 이용약관 위반 소지** — 자동화 프로그램으로 네이버 서비스에 접근하는 것은 약관상 금지되어 있고, 적발 시 **계정 제재(판매 정지 포함)** 가능성이 있습니다. 본인 스토어에 한해, 자기 책임 하에 사용하세요.
2. **낮은 빈도로 돌리세요** — 봇은 답글 사이에 15~40초 랜덤 대기를 넣고, 한 번에 최대 10건만 처리합니다. 하루 1~2회 수동 실행을 권장합니다. 서버에 부담을 주는 사용은 하지 마세요.
3. **셀렉터 조정 필요** — 스마트스토어센터는 로그인 뒤에만 보이는 화면이라, `config.js`의 CSS 셀렉터는 첫 실행 때 실제 화면에 맞게 조정해야 할 수 있습니다. 셀렉터가 안 맞으면 `debug/` 폴더에 스크린샷과 HTML이 저장되므로 그걸 보고 고치면 됩니다.
4. **센터 UI가 바뀌면 깨집니다** — 네이버가 화면을 개편하면 셀렉터를 다시 맞춰야 합니다.
5. **드라이런이 기본** — `--post` 플래그 없이 실행하면 답글을 생성해서 보여주기만 하고 등록하지 않습니다. 먼저 드라이런으로 답글 품질을 확인하세요.

## 설치

```bash
cd smartstore-review-bot
npm install
npx playwright install chromium

cp .env.example .env
# .env 열어서 GEMINI_API_KEY와 STORE_NAME 입력
```

Gemini API 키는 https://aistudio.google.com/apikey 에서 **무료로 발급**합니다 (구글 계정만 있으면 되고, 카드 등록 불필요. 무료 한도로 하루 수백 건 답글 생성 가능).

## 사용법

```bash
# 1. 최초 1회: 브라우저가 열리면 스마트스토어센터에 직접 로그인
#    (2단계 인증 포함. 세션이 user-data/에 저장되어 이후엔 자동 로그인)
npm run login

# 2. 드라이런: 답글을 생성해서 터미널에 보여주기만 함 (등록 X)
npm run dry-run

# 3. 실제 등록
npm run post
```

## 동작 방식

- **중복 방지**: 답글을 단 리뷰는 `replied-log.json`에 기록되어 다시 달지 않습니다.
- **별점 인식**: 3점 이하 리뷰에는 사과 + 해결 방향 제시, 4점 이상에는 감사 + 공감 톤으로 씁니다.
- **자연스러움**: 리뷰에서 언급된 구체적 내용을 짚고, 매번 문장 패턴을 바꿔서 템플릿 티가 나지 않게 합니다. 톤은 `config.js`의 `toneGuide`에서 수정할 수 있습니다.
- **의료광고 규제 준수**: 효능·효과를 단정하는 표현은 쓰지 않도록 프롬프트에 명시되어 있습니다.

## 자주 발생하는 문제

| 증상 | 해결 |
|---|---|
| "리뷰 행을 찾지 못했습니다" | `debug/` 폴더의 HTML을 열어 실제 구조 확인 → `config.js` 셀렉터 수정 |
| 로그인 세션 만료 | `npm run login`으로 다시 로그인 |
| 답글 등록 버튼을 못 찾음 | `config.js`의 `replyButton`/`replySubmit` 셀렉터 조정 |
| 캡차가 뜸 | 실행 빈도를 낮추고, 브라우저 창에서 직접 캡차를 풀어준 뒤 재실행 |
