💊 대체조제 매핑 도구

약국 조제내역 + 요율표 + 건강보험 약가파일(주성분코드) 3개를 올리면, 주성분코드_동일제형 기준으로 대체조제 가능 품목을 요율표에 매핑해 엑셀로 내려줍니다. 모든 처리는 브라우저 안에서만 이루어지며 파일이 서버로 전송되지 않습니다.

① 약국 조제내역

.xls/.xlsx — 약품코드(보험코드)·약품명·조제량·조제금액 열 포함

② 요율표

.xlsx — 성분명·품목명·보험코드 열 포함 (시트 선택 가능)

③ 약가마스터 (건강보험 약가파일)

.xlsx — 주성분코드_동일제형·주성분명·제품코드 열 포함

0약국 품목
0약가파일 매칭
0동일제형 그룹
0요율표 대체가능 행
0보유품목 행
👁 표시할 열 선택 (체크 해제하면 숨김)

매칭 기준: 건강보험 약가파일의 주성분코드_동일제형이 같으면 동일성분·동일함량·동일제형으로 보아 대체조제 가능 후보로 분류합니다.
보유단가 = 같은 성분 보유품목 중 조제량이 가장 많은 품목의 조제단가. 차액 = 후보 약가 − 보유단가 (초록 − = 더 저렴한 대체, 빨강 + = 단가 상승). 정당이익 = 약가 × 요율(코드%) ÷ 100 — 1정(단위)당 이익 금액.
표 머리글을 클릭하면 해당 열 기준 오름차순↔내림차순으로 정렬됩니다. 체크박스로 약가 낮음/동일/높음을 골라 볼 수 있습니다.
⚠️ 실제 대체조제 시 생동성 인정품목 여부(요율표의 생동/생산 열)와 심평원 고시를 최종 확인하세요. 화면에는 최대 2,000행까지 표시되며 전체 결과는 엑셀 다운로드에 포함됩니다.
