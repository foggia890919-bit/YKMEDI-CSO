# 💊 drugtrading — 대체조제 매핑 도구

약국 조제내역과 도매 요율표, 건강보험 약가파일(주성분코드) 3개의 엑셀을 올리면
**동일성분·동일함량·동일제형(대체조제 가능)** 기준으로 요율표를 필터링한 결과 엑셀을 만들어 주는
브라우저 전용 도구입니다. 모든 처리는 브라우저 안에서만 이루어지며 **파일이 서버로 전송되지 않습니다.**

## 사용 방법

1. `index.html`을 브라우저에서 엽니다 (더블클릭, 또는 GitHub Pages 주소 접속).
2. 파일 3개를 업로드합니다.
   - **① 약국 조제내역** (.xls/.xlsx): `약품코드(보험코드)` / `약품명` / `조제량` / `조제금액` 열 포함
   - **② 요율표** (.xlsx): `성분명` / `품목명` / `보험코드` 열 포함 — 시트가 여러 개면 월 시트 선택
   - **③ 약가마스터** (.xlsx): 심평원 「약제급여목록 및 급여상한금액표」 — `주성분코드_동일제형` / `주성분명` / `제품코드` 열 포함
3. **매핑 실행** → 화면에서 검색·구분·주성분 필터로 확인
4. **결과 엑셀 다운로드** → 자동필터가 걸린 3개 시트가 생성됩니다.

## 결과 엑셀 구성

| 시트 | 내용 |
|---|---|
| 대체조제 가능목록 | 요율표 중 약국 보유 성분과 동일제형인 행만 추출. 주성분코드·주성분명·구분(보유품목/대체가능)·약국 보유약품·조제량·조제금액 열이 앞에 추가되고 요율표 원본 열은 그대로 유지 |
| 약국 품목현황 | 약국 품목별 주성분코드 매칭 상태와 요율표 내 대체후보 수 |
| 설명 | 매칭 기준과 주의사항 |

## 매칭 로직

```
약국 약품코드(보험코드 9자리) ──┐
                                ├─→ 약가파일 제품코드 → 주성분코드_동일제형
요율표 보험코드 ────────────────┘
주성분코드_동일제형이 같으면 = 동일성분·동일함량·동일제형 → 대체조제 가능 후보
```

- 헤더 행 위치와 열 순서는 자동 탐색하므로, 열 이름만 맞으면 서식이 달라도 동작합니다.
- 보험코드는 숫자만 추출해 9자리로 맞춰 비교합니다 (앞자리 0 유실 방지).

## ⚠️ 주의

- 실제 대체조제 시 **생동성 인정품목 여부**(요율표의 생동/생산 열)와 심평원 고시를 최종 확인하세요.
- 비급여·일반의약품 등 약가파일에 없는 품목은 "약가파일 미등재"로 분류됩니다.
- 약가파일은 매월 개정되므로 조제내역과 같은 월의 파일을 사용하는 것이 정확합니다.

## GitHub Pages로 호스팅하기

저장소 **Settings → Pages → Branch: `main` / root** 선택 후 저장하면
`https://<계정>.github.io/drugtrading/` 주소로 접속할 수 있습니다.
