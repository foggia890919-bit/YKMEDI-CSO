AI 정밀 인식

Claude AI가 명함 사진을 직접 읽어 기본(무료) 인식보다 훨씬 정확하게 항목을 추출합니다. 서버(Edge Function) 배포가 안 되어 있거나 오류가 나면 자동으로 기본 인식으로 전환되므로 켜두어도 안전합니다.

  1. Supabase CLI에서 supabase functions deploy card-ai-ocr 실행
  2. supabase secrets set ANTHROPIC_API_KEY=sk-ant-… 로 API 키 등록
  3. 자세한 방법은 docs/명함관리-설정가이드.md 참고

구글시트 주소록 실시간 연동

명함을 저장·수정·삭제할 때마다 연결된 구글시트 주소록에 자동으로 반영됩니다.

연동 안 됨

  1. 구글시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 아래 코드를 전체 붙여넣고 저장합니다.
  3. 배포 → 새 배포 → 웹 앱 · 액세스 권한 “모든 사용자”로 배포합니다.
  4. 발급된 웹앱 URL(…/exec)을 위 칸에 붙여넣고 연동 저장을 누릅니다.
